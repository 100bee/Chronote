📦 Chronote 프로젝트 실행 가이드

━━━━━━━━━━━━━━━━━━━━━━━
[1] Node.js 의존성 설치

# client
cd client
npm install

# server
cd ../server
npm install

━━━━━━━━━━━━━━━━━━━━━━━
[2] Python 가상환경 및 의존성 설치 (pyserver 사용 시)

cd ../pyserver

# 가상환경 생성 (최초 1회만)
python -m venv venv

# ✅ 가상환경 활성화 방법 (운영체제에 따라 다름)

# ▶ Windows (명령 프롬프트)
venv\Scripts\activate

# ▶ Windows (PowerShell)
.\venv\Scripts\Activate.ps1

# ▶ macOS / Linux / WSL
source venv/bin/activate

# 가상환경 활성화 후, 의존성 설치
pip install -r requirements.txt

━━━━━━━━━━━━━━━━━━━━━━━
[3] MySQL 초기 스키마 설정 (최초 1회만)

# MySQL에 접속한 후 아래 명령 실행
mysql -u root -p < mysql_init/init_schema.sql

━━━━━━━━━━━━━━━━━━━━━━━
[4] 서버 실행 순서

# 1. 백엔드 API 서버 실행 (server)
cd server
node index.js

# 2. 실시간 소켓 서버 실행 (consumer.js)
node consumer.js

# 3. 프론트엔드 React 앱 실행
cd ../client
npm start

# 4. (선택) Python 서버 실행
cd ../pyserver
# 가상환경 먼저 활성화한 후:
.\venv\Scripts\activate
python main.py

━━━━━━━━━━━━━━━━━━━━━━━
[5] 접속 주소

# 프론트엔드: http://localhost:3000
# 백엔드 API 서버: http://localhost:3001
# Python 서버 (FastAPI 등): http://localhost:8000 (예시)

━━━━━━━━━━━━━━━━━━━━━━━
❗ 주의 사항

- `.env` 파일은 개인별로 직접 생성해야 합니다 (예: DB 비밀번호 등)
- 포트 번호 충돌 시 client/server의 포트를 변경해 주세요
- Git에는 `node_modules/`, `venv/` 폴더가 올라가지 않습니다

MongoDB (그냥 설치)
몽고디비는 그냥 설치하면 NoSQL특성상 코드에 따라 스키마 형성
대신 별도로 Compass를 설치해서 서버가 켜져있는지 확인해야함


설치 라이브러리
1. 파이썬 환경
.\venv\Scripts\activate (가상환경키기)
pip install fastapi uvicorn (다운받기)
python -m uvicorn main:app --reload --port 8000 (서버 실행)

2. Redis
npm install redis



.env (내용)
PORT=3001
JWT_SECRET=ROOT1234
JWT_EXPIRES_IN=7d
MYSQL_HOST=localhost
MYSQL_USER=chronote_user
MYSQL_PASSWORD=1234
MYSQL_DATABASE=chronote_db
