# 크로노트 (Chronote)

AI 기반 학습 관리 플랫폼: 공부 스케줄 관리, 그룹 스터디, AI 피드백, 랭킹 시스템 등을 지원하는 웹/앱 서비스입니다.

---

## 프로젝트 주요 기능

- **To-do 리스트** 기반의 공부 계획 관리
- **그룹 채팅**을 통한 스터디 그룹 소통
- **AI 기반 공부 피드백 및 매칭** 기능
- **타이머 + 랭킹 시스템**으로 동기 부여
- **공부 데이터 시각화 및 분석**

---

## 프로젝트 목적

> 현대의 학습자들이 동기부여를 유지하고, 체계적인 계획 수립과 실행을 도와주는 **스마트 학습 플랫폼** 개발.

---

## 타겟 사용자

- 대학생, 고등학생, 자격증 준비생 등
- 혼자 공부가 어려운 사람들
- 공부를 습관화하고 싶은 사용자
